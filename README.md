# 🔳 Gerador de QR Code

Gerador de QR Code desenvolvido com **HTML, CSS e JavaScript**, capaz de criar códigos QR para diferentes tipos de conteúdo e adicionar uma **imagem ou logo personalizada no centro do QR Code**.

O projeto funciona diretamente no navegador e pode ser hospedado gratuitamente utilizando o **GitHub Pages**.

---

## 🚀 Demonstração

Acesse o projeto pelo GitHub Pages:

**https://henriqss.github.io/QR_CODE/**
